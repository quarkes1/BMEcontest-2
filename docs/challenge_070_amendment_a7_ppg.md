# Amendment A7 PPG候选级增量证据研究设计

2026-10-14。状态：设计与实施计划均已获用户确认；P0代码已实现，39项专项测试通过（含真实进程/提交封存的合成流程），真实数据注册与提取待执行。目标是确认PPG能否补充现有IMU候选复核，最终服务于正式F1达到0.70以上，而非仅展示波形或窗级指标。当前正式F1仍.6514285714，dist/release不变。

## 1. 已知证据与方向选择

24人固定完整文件探查支持按原行序解释约25Hz包内序列；低运动谱峰一致率84.07%、高运动70.65%。但该面板只覆盖97个T24可评估GT中的1个、794个health候选中的24个，不能据此判断进食识别价值。固定约10分钟错时对照显示同时刻一致率77.53%、错时49.20%，只能支持存在时间对应的共同信号，不能排除运动伪影。

本设计选择：**先候选级质量与条件证据审计，再考虑小型融合模型**。两个备选暂不启动：

- 原始PPG Transformer/端到端多模态：解析与标签覆盖未确认，过早增加表示自由度和成本。
- PPG独立候选生成：可能帮助IMU完全漏掉的餐，但改变候选集合，难与复核收益分离，需要全天负时段评价和单独注册。

第一轮只用PPG3/PPG5列名。绿光映射仍属组内声明；25Hz、包时间锚点均为显式假设。不计算HRV，不声称医学心率准确性，不用不同光路拼接成单波形。

## 2. 本次实施范围P0

P0仅新增经过测试的只读解析、质量提取与诊断报告：NO TRAINING / NO THRESHOLD TUNING / NO POLICY CHANGE / NO NEW EVENT F1 / NO V7 OR OUTER READ / NO DIST CHANGE。后文P1是后续研究约束，不属于P0自动执行范围。

输入冻结为A6 t1 manifest及12份wrapper policy/health scores。2411候选出现记录保留原partition与行号；按(sid,start_ms,end_ms)去重得到2034个提取键，227个原始文件、约18.42GiB。不得把去重后的候选当成新随机训练样本。全部受试者必须属于T24；共享索引可读，raw路径解析前须过滤。不得静默替换不可读文件或扩展至V7/outer。

候选包含真、假以及原policy接受/拒绝的全部候选，不按GT筛选提取集合。先不扩大候选召回，不读取没有入选候选的其他T24会话。由此得到的是**候选条件下的**覆盖与信息量，不能称为全天PPG召回。

## 3. 解析和时间合同

按列名读取PPG_TIME、PPG3/PPG5、ACC_TIME及ACC三轴。包内维持原文件次序；禁止不稳定排序、仅按时间戳去重、删除相同量化样本。跨读取chunk携带未完成包。同一时间戳非连续再次出现时记录异常，不把远隔的块强行合并。

实施澄清：异步多传感器表中PPG_TIME/PPG3/PPG5均为零的行属于无PPG观测的占位行，保持包状态；带信号但时间无效的行则打断连续性。两者分别测试并计数。此澄清不把坏值行删除后重组完整包。

执行勘误：首次注册提取在表头即因制表符格式中止，保留原attempt为INCOMPLETE；修复并补充制表符回归测试后，以`amendment_a7_ppg/attempt_02/`重新注册。按表头确定tab/comma分隔符，字段仍严格按列名读取；候选、质量常数和全部统计门槛不变。这是解析修复，不是新的算法或参数搜索。

第二次提取发现一个原始文件第501224行重复表头，保留attempt_02为INCOMPLETE；新增回归测试后，以`attempt_03/`注册。重复表头和非数值单元格计数，转NaN保留其观测位置并切段，不通过删除坏行补全包；CSV结构损坏仍报错。定位该异常的额外只读扫描字节上界2711202907，单独记账。固定谱门槛和候选范围继续不变。

主路径只使用完整15样本包，正包间隔450–750ms；不完整包、倒退和较大缺口均切段，不插值跨越缺口。无效/全零/非有限值须计数，不能通过删除坏行让包重新看似完整。每列零值保留质量标志；成对完整有效窗口不足则输出缺失，不生成默认生理值。

主假设采样25Hz；包锚点按首样本处理，包内时间t+i*40ms。连续段内按原行序每50包产生一个非重叠窗口；谱统计按750样本，支持区间为首包时间至末包时间+600ms，与先前审计一致。保存实际包跨度、完整包比例、局部推算采样率和边界异常，禁止将包数或窗口数当成全天覆盖率。

只做一个预先固定的锚点敏感性诊断：将窗口支持区间整体前移560ms作为“包时间对应末样本”的替代假设，重算候选阶段的覆盖和聚合差异，不重新挑阈值或比较event F1。该范围不涵盖任意回调延迟，报告必须注明。

ACC只提供同窗口内向量模长std，有限非零行至少100。其时序也是包级近似，不计算伪精确的跨模态相位/因果关系。低/高运动分层为描述统计，不能根据整个验证主体的活动分布学习部署路由。

## 4. 固定质量指标与候选时间范围

沿用已冻结的谱计算：独立列去均值，三阶Butterworth .7–3.3Hz零相位滤波，Welch nperseg512，.7–3Hz找峰，峰±.12Hz能量占比。双路占比均>=.15、谱峰差<=1/6Hz才标记pair-pass。它是代理质量标志，不是生理正确标签；不得根据餐次标签调整这些常数。

每个候选固定三阶段：

| 阶段 | 区间 |
| --- | --- |
| pre | candidate_start−20min 至 candidate_start−5min |
| during | candidate_start 至 candidate_end |
| late | candidate_start+10min 至 candidate_start+45min |

late不称为真实餐后，可能与长候选during重叠。只使用同sid内数据，不跨会话拼接；窗口与阶段交集作为聚合权重。覆盖率分母为完整请求阶段时长，不能用裁剪后的可见时长掩盖会话边界缺失。有效覆盖不足保留NaN和原因；任何进一步相对变化都须两阶段数据可用。使用late意味着最多需候选开始后45min数据，本项目按全天离线任务研究，不声称实时。

Q质量/采集对照共9维：每阶段的有效波形时间覆盖率、pair-pass时间覆盖率、有效ACC窗口motion的加权中位数。覆盖是区间并集长度，不能重叠累加超过1。

P时序代理共6维：先在pair-pass窗口内计算双路谱峰均值和每列带通RMS/abs(原列中位数)；每阶段做交集时间加权中位数，再输出during−pre和late−pre的三个差值。分母为零、非有限值或计算溢出时，该窗口对应幅度代理为NaN，不以任意epsilon替代。加权中位数定义为按值升序后累计有效交集权重首次达到总权重50%的值，不作两点平均。阶段pair-pass覆盖>=.5且贡献窗口>=6才可产生阶段代理；单个代理还须其有限值窗口独立满足同样的覆盖和数量门槛。这些门槛仅用于本次审计，不作生理有效性声明。未满足则NaN；不通过插值补齐。频率单位Hz，幅度比无量纲，不命名为HR/HRV。

保存必要阶段中间量以便审计；第一版不搜索波长、窗口、频带、质量阈值或特征子集。固定6维差值旨在减少绝对幅度带来的主体/接触状态混淆，而非宣称完全消除此类偏差。

## 5. 诊断和停止条件

提取不读取候选label、base score或GT；特征与原始输入哈希封存并提交后，报告阶段才能加载原证据标签和分数。P0不调用模型fit、选policy或重新解码事件。

报告至少包含：

1. 每partition/subject的请求时长、有效/pair-pass覆盖、缺失原因及阶段可用数。health主表只计一次，policy记录不能混作独立样本扩大样本量。
2. 原候选正/负标签、原policy接受/拒绝候选的Q/P分布。真候选不等于独立检出GT；不把多个同餐候选算成多个TP。
3. 惯用/非惯用手GT的相关候选可用性；仅诊断，不给负候选虚构手侧标签，不生成分组F1。
4. 固定base分数区间[0,.25)、[.25,.5)、[.5,.75)、[.75,1]内P差异，按wrapper单独报告方向、样本量和缺失。区间不优化，不把观察结果转换成rescue规则。
5. Q与P的相关性及按原始motion代理分层的分布，区分可能的运动/采集解释。样本不足如某组不足5个候选时标为不足，不汇总漂亮AUC。首轮不提供最优阈值、分类AUC排名或性能headline。
6. 主锚点与前移560ms的固定对照下覆盖/6维差值变化。不能按标签选择锚点。

若可用真候选极少、主要只有单一受试者/partition，或Q解释了全部表面差异，先报告证据不足，不启动高容量模型。P0结果只支撑下一研究假设，不存在自动promotion gate。即使有明确差异，也需后续严格训练侧验证。

## 6. 后续P1的三组比较约束

P1须在P0结束后单独注册具体模型、损失、预算和工程门槛，不能在本设计中提前允许不受限训练。

- B：原冻结IMU基线。
- Q：相同融合架构，仅添加质量/缺失/运动信息。
- P：在Q之上添加固定PPG时序差值。

解释PPG新增信息必须比较P对Q，而不仅P对B；若Q获益而P无益，不能声称检测到进食生理响应。PPG不可用时P须与对应IMU对照明确回退一致，不以缺失为拒绝理由。最终评价仍是event TP/FP/FN和F1，兼顾逐人/短餐/手侧诊断，而不是窗级AUC。

严格复用A6嵌套划分，不能把12份OOF拼起来再简单划分训练一个meta模型：其他OOF行的上游producer可能见过当前验证受试者。每个policy split的融合训练数据必须由该split训练主体内部crossfit产生，排除验证主体的全部上游训练；必要时调用现有build_candidate_ledgers重建训练ledger并复现原held-out候选/base评分。无参数、逐会话确定性的PPG缓存可以跨partition共享；归一化/填补/选择/融合/阈值不能共享。全部policy提交冻结后才能运行health。不重开V7/outer，不自动更新dist。

## 7. 工程组织和资源约束

建议研究代码集中在`scripts/research/representation_v2/ppg/`，职责拆为contract、packet解析、window质量、candidate聚合、审计入口；测试集中`tests/research/test_ppg_*.py`。不修改现有注册算法文件，不向src/pipeline或dist接入未验证分支。

P0预算：227文件、raw读取最多一次提取遍历；注册哈希核验的额外I/O须单独记账，不伪称单次物理读取。4个CPU进程，每进程数值库1线程；总内存上限16GiB，提取墙钟上限2h。没有神经训练，GPU不会加速主要的文本解析工作，不为占用显卡增加不必要模型。

新增持久缓存+证据总上限128MiB，磁盘至少保留20GiB；只存紧凑窗口统计、候选特征、输入哈希及manifest，不保存原波形副本。复用需核验raw SHA、schema、采样/锚点/质量常数和版本。任务结束删本任务临时文件，保留复现实验所需小型证据；不删已注册旧模型或用户文件。

注册文件须锁定本设计、代码、12份score证据、manifest和raw清单；状态REGISTERED→EXTRACTED→REPORTED，失败INCOMPLETE不覆盖。输出集中`outputs/challenger_70/representation_v2/amendment_a7_ppg/`。建议产物：registry.json、state.json、resources.json、window_stats.npz、candidate_features.npz、coverage_by_partition.json、conditional_evidence.json、report.md。输出文件本身不得包含访问凭证。

测试必须覆盖：列重排、跨chunk包边界、15个相同量化样本不得去重、部分/重复包、倒序/长缺口、全零/非有限/常数列、频谱正负例、跨session禁止聚合、部分覆盖分母、缺失阶段差值、固定锚点对照、未知受试者/held-out拒读、缓存身份不匹配、重复候选跨partition映射和只读报告不训练。实施计划需给出完整测试与复现命令；审阅设计后再编写计划。
