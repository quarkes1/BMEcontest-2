# 系统设计说明：基于智能手表传感器的进食检测

> 版本 2.0（2026-09-02）——本文档描述最终系统架构、方法与实验结论，供总结报告与代码复核使用。
> 历史实验过程记录（任务编号/迭代日志）不再保留；实验结论以本文与 README 的结果表为准。

## 1. 任务定义与评估口径

- **数据**：华为智能手表全天 IMU（加速度计+陀螺仪，约 105Hz，原始 ADC 无物理单位）
  与 PPG（44 通道，有效采样约 2Hz）。餐次（Episode）级标注为用户自报。
- **双佩戴场景**（竞赛题面要求分别设计）：
  - 惯用手：手部动作特征明显，IMU 运动模式主导；
  - 非惯用手：动作弱甚至不可捕捉，需上下文/生理信号辅助。
- **评估**（全局事件级）：预测与真实 Episode 的 IoU ≥ 0.25 判为正确检出（TP），
  灵敏度 = TP/真实事件数，PPV = TP/预测事件数，F1 = 2·Sens·PPV/(Sens+PPV)；
  次要指标为正确匹配事件的起止时间平均绝对误差（MAE）。

## 2. 系统架构：检测即排序

```
[1s 活动包络(0.5-2Hz 带通) × 24h 时刻先验] → 候选提案（活动连通域 + 时间先验两池）
  → 候选 240s 窗口（±120s 上下文，10Hz，6 通道）
  → 排序：LightGBM（14 维特征）⊕ 深度排序头（TCN，加权融合）
  → 会话级门控（有无餐判别，AUC≈0.88）
  → 解码与形态学后处理 → 事件输出
```

- **提案层**：对 1s 活动包络与时刻先验的乘积做多阈值连通域分析（分位数 75-95%、
  间隔 30/60s、最短时长 5/10s），并以 15 分钟网格时间窗补充稀疏餐的覆盖，两池
  分别合并（重叠 IoU>0.6）。
- **深度排序头（MM-Ranker）**：候选窗口（2400×6，10Hz）经 7 核卷积映射后进入
  6 层膨胀因果卷积残差栈（dilation 2^i，核宽 5），5s 块平均池化后与元特征
  （时长、时刻先验、会话门控概率）经双向 GRU 与多层感知机融合输出候选置信度。
  训练使用 Focal Loss（γ=2）与硬负样本挖掘（对高置信误判负样本提权）。
- **会话门控**：以会话级统计特征（时长、包络分布、开始时刻）训练 LightGBM
  分类器，输出"本会话是否含餐"的概率，用于抑制无餐会话的误报。
- **解码**：深度分与 LightGBM 活动分加权融合后按阈值选窗；先验池按逐窗阈值
  取前 2 个非重叠事件。两路事件合并后进入形态学后处理。

## 3. 外部数据预训练（FD 数据集）

- **数据**：FD-I/FD-II（KU Leuven，61 人全天双腕 IMU，Shimmer3，64Hz，
  咬合级标签 0/1/2 与餐次边界）。
- **预处理**：64Hz 降采样至 10Hz；以"进食手势（标签=1）连续簇、簇间隔 <180s
  合并、边界 ±60s 膨胀"推导餐次（Episode）标注；窗口与餐次重叠 ≥50% 记正样本。
  负样本仅取 FD-I（其 0 标签为全天确认非餐；FD-II 仅在餐时段标注，其 0 不可用）。
- **尺度对齐**：实测 FD 加速度为 m/s² 物理单位而本项目为原始 ADC（幅值差约
  385 倍），故以 FD 全量数据估计每通道均值/标准差，对两边输入统一做 z-score
  归一化，归一化统计量随权重文件保存。
- **训练**：预训练任务与目标任务一致（Episode 级候选分类，而非咬合级——
  咬合级任务与餐次排序不匹配，此为对照实验结论），得到预训练权重
  `checkpoints/fd_pretrained_s1.pt`（验证集 AUC 0.982）。
- **微调**：以预训练权重初始化深度排序头（特征提取层逐层拷贝），在目标数据上
  全量微调。

## 4. 双佩戴场景与路由设计

- 题面要求惯用手/非惯用手分别处理。实测约束：本项目 PPG 有效采样约 2Hz，
  无法做逐拍 HR/HRV 估计；故非惯用手一侧以"弱 IMU + 全天上下文"实现（依赖
  FD 双腕预训练隐含学到的弱信号判别），并保留 PPG 分支接口（在更高采样率
  数据上启用）。
- **自适应路由**：不假定元数据提供佩戴侧（dominant_hand），以会话级 IMU
  4-16Hz 高频能量统计驱动分支权重连续插值；备选硬路由（前 10 分钟能量方差
  阈值硬切换）亦已实现。两者在单侧佩戴验证集上均无增益（见 §6），其价值
  保留于含非惯用手佩戴的测试场景。

## 5. 官方评估与形态学后处理

- 官方后处理流水线：候选置信度映射至 1Hz 全天连续时间轴（重叠窗取最大）→
  60s 平滑 → 阈值截断生成 Episode → 间隔 <180s 的断点连通合并 → 过滤总时长
  <120s 的孤立框 → 边界膨胀。
- 边界膨胀时长经网格搜索确定（30/60/90/120s × 融合间隔 60/120/180s），
  最优为 120s 膨胀 + 180s 融合。

## 6. 实验结果

### 6.1 主结果（5 折交叉验证，全局官方口径均值）

| 系统 | 现有后处理 F1 | 官方流水线 F1 |
|---|---|---|
| 无预训练基线 | 0.298 | 0.159 |
| **FD 预训练微调（最终）** | **0.333** | 0.210（膨胀寻优后 0.240） |

逐折（FD 预训练，现有后处理）：0.367 / 0.258 / 0.364 / 0.229 / 0.447。

### 6.2 消融与对照

| 变更 | 效果 | 说明 |
|---|---|---|
| FD Episode 级预训练 | +0.035（5 折全正向） | 任务对齐+全天负样本+尺度归一 |
| 官方流水线膨胀寻优 | +0.030 | dilation 单调增益 |
| 增加 gyro 4-16Hz 高频通道 | -0.008 | 预训练已含该频段判别 |
| 冻结 TCN 前 3 层微调 | -0.034（fold0） | 全量微调最优 |
| 自适应/硬路由 | -0.059/-0.087 | 单侧佩戴下深度分为主导信号，降权有害 |
| 损失提权（α0.75 / 非对称损失） | -0.014/-0.016（fold1） | 置信度分布变化未转化为事件级增益 |
| 会话级 Instance Normalization | -0.025（fold1） | 破坏预训练期望的全局尺度 |
| PPG 分支 / 咬合级预训练 | 无增益 | 采样率不足 / 任务不匹配 |

### 6.3 标签时间偏移分析（可达性上界）

测量全部验证餐次的标注中心与 IMU 活动峰值（0.5-2Hz 包络）的时间差：
5 折偏移中位 10.2-11.8 分钟，偏移超过 9 分钟的餐占比 54-74%。

**推导**：设餐长 D（中位约 15 分钟）、标注偏移 δ，检测器即使完美复现真实进食
时段，其与标注的 IoU = (D−δ)/(D+δ)，要求 IoU ≥ 0.25 即 δ ≤ 0.6·D ≈ 9 分钟。
因此偏移超过 9 分钟的餐在匹配上不可达——用户自报标注的时间精度构成了
评估分数的事实上界，当前 0.333 已接近该上界（各折理论上限约 26-46%）。

## 7. 局限与展望

- 排序头对真餐候选打分整体偏低的历史现象，最终归因于标注时间噪声与单侧
  佩戴数据的信号强度，而非训练目标或归一化可解。
- 展望：标注时间校准、更高采样率 PPG、含非惯用手佩戴的测试数据下启用路由、
  FD-II 域外验证。
