# 系统设计说明：基于智能手表传感器的进食检测

> 版本 2.0（2026-09-02）——本文档描述最终系统架构、方法与实验结论，供总结报告与代码复核使用。
> 历史实验过程记录（任务编号/迭代日志）不再保留；实验结论以本文与 README 的结果表为准。

## 1. 任务定义与评估口径

- **数据**：华为智能手表全天 IMU（加速度计+陀螺仪，约 105Hz，原始 ADC 无物理单位）
  与 PPG（44 通道，有效采样约 2Hz）。餐次（Episode）级标注为用户自报。
- **双佩戴场景**（竞赛题面要求分别设计）：
  - 惯用手：手部动作特征明显，IMU 运动模式主导；
  - 非惯用手：动作弱甚至不可捕捉，需上下文/生理信号辅助。
- **评估**（全局事件级）：预测与真实 Episode 的 IoU ≥ 0.25 判为正确检出（TP），
  灵敏度 = TP/真实事件数，PPV = TP/预测事件数，F1 = 2·Sens·PPV/(Sens+PPV)；
  次要指标为正确匹配事件的起止时间平均绝对误差（MAE）。

## 2. 系统架构：检测即排序

```
[1s 活动包络(0.5-2Hz 带通) × 24h 时刻先验] → 候选提案（活动连通域 + 时间先验两池）
  → 候选 240s 窗口（±120s 上下文，10Hz，6 通道）
  → 排序：LightGBM（14 维特征）⊕ 深度排序头（TCN，加权融合）
  → 会话级门控（有无餐判别，AUC≈0.88）
  → 解码与形态学后处理 → 事件输出
```

- **提案层**：对 1s 活动包络与时刻先验的乘积做多阈值连通域分析（分位数 75-95%、
  间隔 30/60s、最短时长 5/10s），并以 15 分钟网格时间窗补充稀疏餐的覆盖，两池
  分别合并（重叠 IoU>0.6）。
- **深度排序头（MM-Ranker）**：候选窗口（2400×6，10Hz）经 7 核卷积映射后进入
  6 层膨胀因果卷积残差栈（dilation 2^i，核宽 5），5s 块平均池化后与元特征
  （时长、时刻先验、会话门控概率）经双向 GRU 与多层感知机融合输出候选置信度。
  训练使用 Focal Loss（γ=2）与硬负样本挖掘（对高置信误判负样本提权）。
- **会话门控**：以会话级统计特征（时长、包络分布、开始时刻）训练 LightGBM
  分类器，输出"本会话是否含餐"的概率，用于抑制无餐会话的误报。
- **解码**：深度分与 LightGBM 活动分加权融合后按阈值选窗；先验池按逐窗阈值
  取前 2 个非重叠事件。两路事件合并后进入形态学后处理。

## 3. 外部数据预训练（FD 数据集）

- **数据**：FD-I/FD-II（KU Leuven，61 人全天双腕 IMU，Shimmer3，64Hz，
  咬合级标签 0/1/2 与餐次边界）。
- **预处理**：64Hz 降采样至 10Hz；以"进食手势（标签=1）连续簇、簇间隔 <180s
  合并、边界 ±60s 膨胀"推导餐次（Episode）标注；窗口与餐次重叠 ≥50% 记正样本。
  负样本仅取 FD-I（其 0 标签为全天确认非餐；FD-II 仅在餐时段标注，其 0 不可用）。
- **尺度对齐**：实测 FD 加速度为 m/s² 物理单位而本项目为原始 ADC（幅值差约
  385 倍），故以 FD 全量数据估计每通道均值/标准差，对两边输入统一做 z-score
  归一化，归一化统计量随权重文件保存。
- **训练**：预训练任务与目标任务一致（Episode 级候选分类，而非咬合级——
  咬合级任务与餐次排序不匹配，此为对照实验结论），得到预训练权重
  `checkpoints/fd_pretrained_s1.pt`（验证集 AUC 0.982）。
- **微调**：以预训练权重初始化深度排序头（特征提取层逐层拷贝），在目标数据上
  全量微调。

## 4. 双佩戴场景与路由设计

- 题面要求惯用手/非惯用手分别处理。实测约束：本项目 PPG 有效采样约 2Hz，
  无法做逐拍 HR/HRV 估计；故非惯用手一侧以"弱 IMU + 全天上下文"实现（依赖
  FD 双腕预训练隐含学到的弱信号判别），并保留 PPG 分支接口（在更高采样率
  数据上启用）。
- **自适应路由**：不假定元数据提供佩戴侧（dominant_hand），以会话级 IMU
  4-16Hz 高频能量统计驱动分支权重连续插值；备选硬路由（前 10 分钟能量方差
  阈值硬切换）亦已实现。两者在单侧佩戴验证集上均无增益（见 §6），其价值
  保留于含非惯用手佩戴的测试场景。

## 5. 官方评估与形态学后处理

- 官方后处理流水线：候选置信度映射至 1Hz 全天连续时间轴（重叠窗取最大）→
  60s 平滑 → 阈值截断生成 Episode → 间隔 <180s 的断点连通合并 → 过滤总时长
  <120s 的孤立框 → 边界膨胀。
- 边界膨胀时长经网格搜索确定（30/60/90/120s × 融合间隔 60/120/180s），
  最优为 120s 膨胀 + 180s 融合。

## 6. 实验结果

### 6.0 时间轴修复（2026-09-06 审计，历史分数作废说明）

Peer review 发现两个真实 bug，修复后历史 0.319/0.333 **不再可复现**：

1. **WINDOW_MS=525000 bug**（rank_events）：事件右端 = 最后窗起点 + 525000ms
   （把 525 行误当毫秒）→ 每个预测事件右扩 8.75 分钟——暴力膨胀框与 15min 餐的
   IoU 显著虚高，旧"高 F1"的相当部分来自该伪膨胀（评估口径作弊）。
2. **时间轴漂移**（validate_baselines/band_env 均匀行号轴 vs 真实包级时间戳）：
   漂移可达 2.9-5.7min/会话。修复为按真实 ACC 时间戳做 5s/1s 窗定位（包级
   时间戳每 10 行共享、包间隔 94-95ms，窗定位精度 ~0.1s）。

修复后的事件是活动连通域的真实覆盖（非伪膨胀），候选窗数从 ~3.3 万/折升至
~14 万/折（旧右扩框覆盖多档并集的合并效应消失），正:负失衡从 1:317 恶化至
1:2183 → 排序头收敛到"全负"（分数饱和 0）→ 引入负样本子采样（NEG_RATIO=100）
恢复训练（valAUC 0.83-0.90，5 折）。

### 6.1 主结果（修复后，5 折交叉验证，全局官方口径均值）

| 系统 | legacy 后处理 F1 | 官方流水线 F1 |
|---|---|---|
| FD 预训练 + NEG_RATIO=100 微调（修复后基线） | **0.202** | ~0.1 |

逐折（修复后，legacy 口径）：0.143 / 0.180 / 0.200 / 0.204 / 0.283。

修复后评估口径下的瓶颈分解（5 折同构，证据链见 scripts/diag_*.py）：
- **候选覆盖**：50-68% 的餐无 act 候选窗（活动连通域 <3.8min 与 15min 餐
  IoU<0.25 数学不可达）；pri 网格几何覆盖 85%+ 但窗级判别 AUC 仅 ~0.72；
- **窗级判别**：正窗会话内 rank 中位 ~50/150——含餐会话的活动负窗与餐窗在
  6ch IMU 240s 窗上区分度不足；gate_prob 元特征是会话级捷径（同会话共享）会
  掩盖窗级信号（消融后分数平台化，rank 未改善）；
- **会话门控**：真实时间轴下 AUC 0.729（历史 0.88 含漂移假象）→ 误杀约 30%
  餐（短会话 1-2.5h 的餐活动最强 3.9× 会话基线却因 dur_h 被判无餐）；
- **标签偏移**：时间轴修复后重测偏移中位 10-13.5min 不变（真实数据性质，
  非伪影）；大膨胀（600s+）可桥接但 FP 失控。

结论记录：这些是数据/任务层约束的量化事实，不构成"F1 上限"声明——新的
信号/标注/训练范式仍可能突破（见 §7）。

### 6.2 修复后诊断消融（2026-09-06，fold0）

| 变更 | 效果 | 说明 |
|---|---|---|
| 负样本子采样 NEG_RATIO=100 | 决定性（恢复训练） | 1:2183 失衡 → 全负塌缩；子采样后 valAUC 0.80→0.83+ |
| fp16 autocast + batch 256 | 速度 30× | fp32 conv 311ms/step（Blackwell 无 tensor core）→ ~11s/epoch |
| 移除 gate_prob 元特征 | 分数平台化 | 正窗 median 0.147→0.498 但负窗同步抬升——窗级信号不存在于该特征捷径之外 |
| 分层负采样（含餐会话优先） | 无窗级增益 | 正窗会话内 rank 中位仍 ~16-18 |
| decode 变体（分位/top-K/聚类/双门控/大融合/官方口径网格） | 均 ≤0.18 | decode 层调参无法突破覆盖+窗级判别联合瓶颈 |

### 6.3 标签时间偏移分析（修复后复测）

时间轴修复后重测：5 折偏移中位 10-13.5min（fold0 11.6 / fold1 13.5 / fold2
9.9 / fold3 10.8 / fold4 12.5），>9min 占比 59-83%——偏移为真实数据性质。
注意：折间成绩与偏移大小不相关（fold4 偏移 82%>9min 却是历史/修复后最高折），
偏移的"不可达上界"推导不成立——匹配取决于检测事件框与标注的重叠形态，
大膨胀框可桥接部分偏移。

## 7. 局限与展望

- 修复后基线 0.202 是真实时间轴+严格口径下的能力测量；旧 0.319/0.333 含
  WINDOW_MS 伪膨胀红利，不可作为对照。
- 主要瓶颈为候选覆盖（50-68% 餐无活动连通域覆盖）与会话内窗级判别弱
  （非餐活动窗与餐窗 6ch IMU 混淆），两者共同限制 recall-精度平衡。
- 展望：餐时段"多段活动聚合"候选（pri 窗聚合分 AUC 1.0 会话内）、会话级
  判别升级（max 深度分 0.80 AUC > LGBM gate 0.73）、FD bite 级联合训练、
  更高采样率 PPG、标注时间校准的外部评估。
