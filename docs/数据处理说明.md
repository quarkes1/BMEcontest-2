# 数据处理说明

## 数据来源
- HUAWEI Research 平台下载（项目：第十一届…赛题二_训练集），2026-06-20 ~ 2026-08-13
- 原始：1165 会话 / 45 受试者（含 test）/ 100GB TSV；下载 0 失败
- 下载后规范化：GBK→UTF-8、表头提行（原脚本 reverse-sort 致表头乱序）、附件路径与本地目录 1165/1165 校验一致

## 剔除规则（scripts/validate_data.py 产出，outputs/data_quality.json）
- **test 用户**：2 会话 + 1 无效标签（before==after），全部剔除
- **空 externalid 会话**：2 行（索引 CSV 中受试者 ID 缺失），无法归属受试者，剔除
- **二进制损坏会话**：16 个（1.4%，分布于 11 名受试者），首 512 字节非文本比例 <90% 判定，列入黑名单 outputs/data_quality_blacklist.txt
- **无效标签**：after<=before 的餐次记录剔除（7 条）
- 数据中的重复行（~5.9%）保留（窗口特征对其不敏感），W2 训练管线再决定去重策略

## 占空比采样（重要语义）
- PPG 78% 行为全零：**不是缺失，是采样调度**（PPG 按块采样，~24 行/s 有效，44 通道窗口等效 ~1kHz）
- ACC/GYRO ~7.3% 行全零：同理
- loader.py 输出 imu_valid/ppg_valid 掩码；无效行时间戳置 -1

## 时间网格与窗口
- 行空间即时间网格：IMU 行率 ~105Hz（实测中位 105.9-113 行/s）；会话级 row_rate 记录于 meta
- 窗口：5s=525 行，步长 1s=105 行；L3b 计划 30s 窗/10s 步长
- 标签：窗口与任一餐时间区间 IoU≥0.5 → 正；=0 → 负；灰区丢弃（训练）
- 灰区窗口在特征缓存中 y=-1

## 场景定义
- 惯用手场景 dominant：wearHand == dietaryHand（~112 餐）
- 非惯用手场景 nondominant：wearHand != dietaryHand（~176 餐）

## 划分
- 按受试者 GroupKFold 5 折（45 受试者，每折 ~9 人），seed=42，manifest 落盘 cache/splits/fold{k}.json

## 低行率会话（补充）
- 3 个会话 row_rate < 4（fs=0.5/1.9/3.9，长空档型：如 11h 会话仅 ~17 分钟有效数据）
- 处理：带通特征在 fs<=4 时降级为零（window_features 内置防护，推理管线同样适用），不崩溃不丢弃
- 依据：用户明确要求测试集可能含异常数据，管线必须容错
