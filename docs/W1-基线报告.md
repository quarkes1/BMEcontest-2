## 3. 结论

- 手工特征 LightGBM 基线 F1≈0.11：对 15 分钟级事件用 5s 窗口统计特征判别力有限，符合预期——基线的定位是对照组，为 W2 深度学习（L3a CNN 等）提供"必须超越"的参考线
- 管线全链路已验证：数据 → 特征 → 训练 → 事件解码 → 竞赛口径评估，一次跑通

## 4. 关键踩坑记录（已修复并归档）

1. **标签规则**：事件级 IoU≥0.5 对 5s 窗口 vs 15min 事件数学上不可能（IoU<0.01）→ 改为"重叠占窗口时长比例≥0.5"（spec 已更新）
2. **内存**：408 万窗口全量驻留 → OOM → mmap + 按会话增量抽样（峰值 ~2GB）
3. **多实例/阶段门禁**：曾因并行启动多个流水线实例与缓存崩溃后带病跑基线 → run_w1_pipeline.sh 加阶段门禁 + 启动清旧报告
4. **评估口径**：正窗口重建真值会因餐内空档把 1 餐拆成 2.35 事件 → 改为餐标签直取（与竞赛口径一致）
