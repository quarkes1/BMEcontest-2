# Challenger E00/E01 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Replay frozen outer-fold evidence without retraining, then emit a deterministic OOF FN/FP Error Atlas while proving incumbent release and `dist` are unchanged.

**Architecture:** A challenger-only replay layer reads verified outer bundles, the attested promotion summary, and validation feature caches. It uses frozen model/policy objects and never calls `run_outer_fold`. A pure atlas layer labels the completed trace only after all candidate decisions are immutable.

**Tech Stack:** Python 3.11, NumPy, frozen sklearn/LightGBM models, pytest, canonical candidate/admission/event primitives.

**Spec:** `docs/challenge设计任务书.md` §§0–10, 22–24, 30–32, 40–45, 54–56.

## Audit Finding

Verified outer bundles have models, direct `RunConfig`, selected admission/event policy, schema, metrics and fingerprints. They omit candidates, windows/scores, matches, eligible GT, and `micro_threshold`. The latter exists only in attested `promotion_summary.json.folds[]` keyed by `outer_fold`. Therefore a bundle alone cannot produce the requested atlas. Exact replay is feasible from registry/attestation + promotion summary + five verified outer bundles + source-fingerprinted split/session caches. A read-only manual fold-0 replay produced exactly 713 raw-union candidates, 42 admitted, 35 predictions and 16/23/35.
