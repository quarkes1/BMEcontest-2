# A7 PPG P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 建议主代理顺序实施，不自动派遣子代理。

**Goal:** 对冻结T24候选提取可审计PPG质量与时序代理，回答可用性和条件增量问题，不训练或评价新算法。

**Architecture:** 候选清单→无标签逐文件提取→固定候选聚合→提交封存→只读条件报告。提取结果按唯一候选共享，但分区记录、主体归属与报告保持独立。

**Tech Stack:** 现有Python环境、NumPy、SciPy、pandas、pytest；标准库进程池；不新增依赖。

**Spec:** `docs/challenge_070_amendment_a7_ppg.md`（用户已批准）；本计划待用户审阅后实施。

## Global Constraints

- NO TRAINING / NO THRESHOLD TUNING / NO POLICY CHANGE / NO NEW EVENT F1 / NO V7 OR OUTER READ / NO DIST CHANGE。
- 仅P0；P1三组融合须另行注册。正式F1仍.6514285714。
- 12份原T1评分证据，2411条出现记录、2034个唯一候选、227文件；清单偏离即失败，不换样本。
- PPG3/PPG5、25Hz、15样本完整包、450–750ms包间隔、50包窗口；保持原行序，不去重量化样本。
- 固定3阶.7–3.3Hz带通、Welch512、.7–3Hz峰、±.12Hz能量占比；双路>=.15及峰差<=1/6Hz。
- pre=start−20min..start−5min，during=start..end，late=start+10min..start+45min；同sid、完整请求时长分母。
- 固定Q9维/P6维；pair-pass覆盖>=.5且>=6窗口；每个代理有限值单独过门槛；不填补缺失。
- 4CPU进程、每进程数值库1线程、总RSS<=16GiB、提取<=2h、新持久文件<=128MiB、磁盘空闲>=20GiB。
- 原始提取一次遍历，哈希核验额外I/O另计；不保留波形副本，不改旧注册代码，不删历史证据。
- REGISTERED→EXTRACTED→REPORTED，异常INCOMPLETE；禁止静默覆盖或失败后自动重试。

## Review Focus

1. 时间戳无效行不能从包中悄悄消失；跨chunk未完成包必须携带（任务2）。
2. 段间窗口支持可因时间抖动局部重叠；覆盖用区间并集，不累加超过1（任务3）。
3. 同一候选跨partition重复；输出映射保留出现记录，不能放大health样本数（任务1/5）。
4. 中断、磁盘不足或源文件在提取期间变化；禁止发布半成品或使用旧缓存（任务4）。
5. 最终预测与候选不是保证一一对应；无法确切映射的接受状态须unknown，不用IoU猜测（任务5）。

- `report.py`: `describe(values: np.ndarray) -> dict`、`build_report(root: Path) -> None`；CLI `python -m scripts.research.representation_v2.ppg.report`。
