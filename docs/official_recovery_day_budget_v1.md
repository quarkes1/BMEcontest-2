# DAY-BUDGET-V1：冻结分数的多天候选预算对照

2026-10-20，训练侧开发实验，不是封存outer的再次调参，也不是正式成绩。

## 根据和固定假设

覆盖审计发现多天文件按人联合推理，而正式策略对整个人的所有天合计限制6个候选；完整本地标签中18人超过6餐。该理论限制不等于官方漏餐的已证实原因。完整事件重标实验仅+.00565、1/3折改善，不能进入交付；本实验不沿用其B verifier。

固定EVENT-COVERAGE-V1完整性重放产生的**old臂**候选、116D特征与评分。仅比较候选预算group：

- S：按主体全部记录合计cap。
- D：按主体×UTC+8自然日分别cap，日期用候选中心时间确定，午夜不拆候选。

不改变NMS（仍同session）、不合并候选、不重新训练/评分、不增加特征。两臂均以完整主体GT、严格IoU>0.25选择和评价策略。完整GT无候选餐保留分母。

## 训练与评价

复用原九份独立policy OOF账本及三份health账本；每份上游生产器和verifier只在对应train受试者拟合，核对祖先图和身份。只用训练policy OOF选NMS(.3,.5,.7)、admission(.2,.35,.5,.65)、cap(3,4,5,6,8)、事件阈值；candidate最低召回.8及fallback不变。两臂网格相同，仅预算归属不同。

全部三折S/D策略文件写完后，才解析/评价任何health分数；启动时可对源文件做不解析分数的字节SHA。不能用health定cap或时间范围。完整标签口径统一，因此S不等于之前用旧eligible标签选策略的旧臂，不混报两次实验。

T24已反复用于开发，不能把本次三折当独立验证；V7和outer仍不参与此实验。门槛固定pooled完整餐次F1 D-S>=.01且至少2/3折提高，强制报告TP/FP/FN、逐人改善/恶化及每折策略。通过仅支持进一步验证，不直接更新dist或承诺隐藏测试提高。
