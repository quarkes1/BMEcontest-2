## 关键决策

- **L3a 训练数据**：正样本 = dominant 场景餐窗口（步长 1s 全保留）；负样本 = 无餐窗口（步长 5s，自然 ~3:1）。nondominant 正样本不入 L3a（该分支归 L3b，W3）。
- **餐具辅助头 5 类**（实测：筷子 210/无需餐具 24/勺 20/手 20/刀叉 7；spec 写 7 类为笔误，以数据为准）。
- **验证打分**：验证窗口缓存（步长 1s 全窗口，~4GB/折，用后即删）→ GPU 批量打分 → 阈值扫描 0.3-0.7 → 事件后处理（src/infer/events.py，W3 推理复用）。
- **内存纪律**（延续 W1 教训）：mmap/流式、LRU 缓存 2 文件、8 进程封顶、验证缓存用完即删。
- **姿态约定**：pitch/roll 绝对（重力方向）、yaw 相对（静止段归零）；静止 = 加速度稳定且角速度 <0.15 rad/s。

## 风险与对策

- torch cu128 下载失败 → 换 cu126 或 CPU 版（CPU 训练 2 折会慢 ~5 倍，备选降低 batch/epochs）
- AMP fp16 数值不稳定 → 关 AMP 用 fp32（5060 显存 8GB 足够）
- 验证缓存磁盘超预算 → 每折训练完即删该折 val 缓存
- L3a 两折 F1 过低（<0.3）→ 先查正样本占比与窗口分布，必要时调正样本步长/阈值口径，不硬调超参凑数
