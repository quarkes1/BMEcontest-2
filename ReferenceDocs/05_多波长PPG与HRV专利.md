# 05 — 多波长 PPG 与 HRV 进食检测专利

## 文献 1：华为 EP4186416（多波长心率测量——本竞赛传感器同源技术）
- **链接**：http://data.epo.org/publication-server/rest/v1.2/patents/EP4186416NWA1/document.pdf
- **核心内容**：第一光信号 **492–577nm（绿光）** 对血容量变化敏感；第二光信号 **1000–1500nm（红外）** 用于**估计第一信号中的噪声**并消除——两波长对运动噪声响应相似、对血容量响应不同 → 噪声抵消
- **启示（L3b 直接采用）**：竞赛数据 44 通道 PPG 大概率是多波长/多空间通道阵列 → **用通道间相关性做运动伪影噪声抵消**有专利方法背书，且能写进"设计原理"
- 附：华为 TruSeen 技术演进（4→8 通道环状光路、曲面蓝宝石）佐证竞赛手表传感器为多通道阵列（公开报道：https://www.ofweek.com/medical/2022-06/ART-8460-1111-30564421.html）

## 文献 2：EP3387989A1（HRV 进食检测）
- **链接**：http://szpa.org/download_files/%e5%8c%bb%e7%96%97%e5%99%a8%e6%a2%b0/1.(%e7%9b%91%e6%8a%a4)%e7%94%9f%e5%91%bd%e4%bf%a1%e6%81%af%e4%b8%8e%e6%94%af%e6%8c%81/%e6%ac%a7%e6%b4%b2/20200709024740292%ef%bc%883501-4000%e6%9d%a1%ef%bc%89/pdf/EP3387989A1.PDF
- **核心内容**：基于"**HRV（RR 间期变异性）受进食影响**"这一发现，用 PPG/ECG 等测 HRV 识别进食时段；建议与活动测量（加速度计/陀螺仪）融合提升可靠性
- **启示**：HRV 进食检测思路的专利先例；"HRV + 活动融合"与我们的动态融合层思路一致

## 文献 3：US20210307686A1 / US11064942B1（多信号融合进食检测）
- **链接**：https://patents.google.com/patent/US20210307686A1/en
- **核心内容**：CGM/血糖 + PPG + 心率 + 加速度计多准则确认进食片段；用 **LSTM、HMM** 对手口动作建模预测未来进食事件；PPG 读数对血糖+加速度读数有增量预测价值
- **启示**：多模态"准则确认 + 学习模型"的架构先例；我们的"动态可靠性加权融合"与之呼应（区别：我们按 PPG SNR/灌注指数实时加权，不是硬准则）
